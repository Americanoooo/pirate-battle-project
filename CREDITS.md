# Credits and licenses

## Game assets

All game art, UI art and sound effects come from the asset pack provided with the Jungle Gaming
"Pirate Battle" developer challenge (`assets/`, kept unmodified). They are used only for this challenge.

Derived runtime files in `public/assets/` are generated by `scripts/prepare-assets.mjs`:

* `atlas/ships.json` — the Starling/Sparrow XML atlas converted to Pixi's JSON hash format.
* `atlas/tiles*.json` — frame definitions for the 64 px tile grid (88 tiles, numbered row-major from 1).
* `atlas/ui*.json` — the provided UI atlases with the image name updated and the DOM-only `ui` metadata removed.
* `sounds/*.mp3` — the provided WAV files encoded to MP3 with ffmpeg (mono 64 kbps for effects,
  stereo 96 kbps for loops) to reduce download size.
